# 组件使用说明

本文覆盖 RCL（`TailAdmin.Templates.Rcl`）的布局、配置、Razor 组件与前端 JS API。所有示例均取自示例宿主，可直接复制。

## 1. 布局

| 布局 | 用途 |
| --- | --- |
| `~/Views/Shared/_TailAdminLayout.cshtml` | 后台主框架：侧边栏 + 顶栏 + 内容区 + Toast |
| `~/Views/Shared/_TailAdminAuthLayout.cshtml` | 登录/注册等无侧栏页面 |

页面通过 ViewData 与布局约定：

```cshtml
@{
    ViewData["Title"] = "商品管理";             // 页面标题（同时写入 <title>）
    ViewData["Subtitle"] = "列表与弹窗示例";     // 可选副标题
    ViewData["MenuKey"] = "goods";              // 必填，需存在于 AdminUi:Menu
    ViewData["Breadcrumb"] = new[] { "後台", "商品中心", "商品管理" };
    ViewData["UseDatepicker"] = true;           // 可选，按需引入 flatpickr
}
@section PageActions {
    <button type="button" class="inline-flex items-center justify-center gap-2 rounded-lg bg-brand-500 px-4 py-2.5 text-theme-sm font-medium text-white shadow-theme-xs transition-colors hover:bg-brand-600">新增</button>
}
@section Styles { /* 可选，追加 CSS */ }
@section Scripts { /* 可选，页面脚本 */ }
```

> `MenuKey` 在开发环境若不存在会直接抛异常；生产环境只记录警告且不做高亮。

## 2. 配置（appsettings.json）

```json
"AdminUi": {
  "SiteName": "商城運營後台",
  "LogoUrl": "",
  "BrandName": "als",
  "DefaultTheme": "system",
  "SidebarCollapsed": false,
  "EnableSearch": false,
  "SearchUrl": "",
  "LoginPath": "/Admin/Account/Login",
  "LogoutPath": "/Admin/Account/Logout",
  "Menu": { "Items": [ { "Key": "goods", "Title": "商品管理", "Icon": "goods",
                          "Area": "Admin", "Controller": "Goods", "Action": "Index",
                          "Permission": "goods" } ] }
}
```

菜单项字段：`Key / Title / Icon / Area / Controller / Action / Url / Permission / NewWindow / Children`。
图标名支持：`dashboard goods tag image order user chart settings search menu sun moon plus chevron-left chevron-right logout upload trash pencil refresh bell check alert empty`。

注册服务：

```csharp
builder.Services.AddTailAdminUi(builder.Configuration);
builder.Services.AddScoped<ICurrentAdmin, MyCurrentAdmin>(); // 宿主实现，读取 Claims
```

`ICurrentAdmin` 需要提供 `IsAuthenticated / UserName / DisplayName / Permissions`；权限包含 `"*"` 即全部放行。

## 3. Razor Partial

### 3.1 `_TableToolbar`

顶部工具栏：**查询**按钮 + 查询弹窗（回车确认、留空查全部），可选新增按钮。

```cshtml
<partial name="_TableToolbar" model="new TableToolbarModel {
    TableId = "goodsTable",
    Description = "支援關鍵字查詢",
    Placeholder = "搜索商品名稱",
    CreateText = "新增商品",              // 可选
    CreateModalId = "goodsEdit",         // 可选
    CreateUrl = Url.Action("EditForm", "Goods", new { area = "Admin" })
}" />
```

### 3.2 `_TaTable`

统一表格：表头排序、加载骨架、错误重试、空态、分页、行操作。

```cshtml
@{
    var table = new TaTableModel
    {
        Id = "goodsTable",
        Url = Url.Action("List", "Goods", new { area = "Admin" }),
        RowKey = "Id",
        PageSize = 20,
        EmptyText = "暫無數據",
        ReloadOn = new List<string> { "goodsEdit" }, // 这些弹窗提交后自动刷新
        OnAction = "edit: function(row){ Ta.modal.load('goodsEdit', '/Admin/Goods/EditForm', { Id: row.Id }); }",
        Columns = new List<TaColumnModel>
        {
            new() { Key = "GoodsName", Label = "商品名稱" },
            new() { Key = "Price", Label = "價格", Type = "money", Align = "right" },
            new() { Key = "PicUrl", Label = "圖片", Type = "image", Width = 72, Sortable = false },
            new() { Key = "IsHot", Label = "熱銷", Type = "bool", Align = "center", Sortable = false }
        },
        Actions = new List<TaActionModel>
        {
            new() { Label = "編輯", Event = "edit", Variant = "primary" },
            new() { Label = "刪除", Event = "delete", Variant = "error" }
        }
    };
}
<partial name="_TaTable" model="table" />
```

列类型：`text`（默认）、`number`、`money`、`date`、`bool`、`tag`、`image`、`link`。
`formatter` 可指定 `Ta.format` 中已注册的函数名，页面可自行扩展 `Ta.format.xxx`。

#### 固定列

`_TaTable` 支持 layui 风格的固定列：左右两侧固定列不随横向滚动，中间区域独立横向滚动；滚动到边界时固定列显示投影与分隔线，表头、表体与行悬停背景保持一致。

配置方式（全部由列模型控制，无需写 CSS）：

```cshtml
var table = new TaTableModel
{
    // ...
    FixedSelectable = true,   // 可选：多选列吸附左侧
    FixedActions = true,      // 可选：操作列吸附右侧
    Columns = new List<TaColumnModel>
    {
        new() { Key = "GoodsName", Label = "商品名稱", Fixed = "left", Width = 180 },
        new() { Key = "PicUrl", Label = "圖片", Type = "image", Fixed = "left", Width = 72, Sortable = false },
        new() { Key = "Price", Label = "價格", Type = "money", Align = "right" },
        // ...
    }
};
```

- 列级：`TaColumnModel.Fixed` 取 `"left"` 或 `"right"`；`null` / `"none"` 表示不固定。
- 多选列：`TaTableModel.FixedSelectable = true` 固定在左侧。
- 操作列：`TaTableModel.FixedActions = true` 固定在右侧。
- 约束：左侧固定列必须是最左的**连续**列，右侧固定列必须是最右的**连续**列。
- `Width` 仅作为首选宽度（未设置时默认 160px）。多列固定时组件会在渲染后按表头**实际宽度**重算 `left` / `right` 偏移并监听窗口缩放，避免自动布局压缩/撑开列宽后出现缝隙或重叠。
- 实现采用原生 `position: sticky`（而非 layui 的左右克隆层），表头与表体共用同一列布局，不存在克隆层与主表滚动不同步的问题。

### 3.3 `_EmptyState` / `_Pagination`

`_Pagination` 由 `_TaTable` 内部引用，无需单独调用。空态用法：

```cshtml
<partial name="_EmptyState" model="new EmptyStateModel {
    Title = "暫無消息", Description = "稍後再來看看",
    ActionText = "返回首頁", ActionUrl = "/Admin/Home/Index"
}" />
```

## 4. 表单 TagHelper

```cshtml
<form method="post" asp-area="Admin" asp-controller="Goods" asp-action="Save"
      x-data="taForm()" x-on:submit.prevent="submit($el)">
    <input type="hidden" asp-for="Id" />
    <ta-input asp-for="GoodsName" label="商品名稱" required placeholder="請輸入" />
    <ta-input asp-for="Price" label="價格" type="number" step="0.01" min="0" />
    <ta-select asp-for="TypeId" label="分類" items="types" required />
    <ta-textarea asp-for="Remark" label="備註" rows="3" />
    <ta-toggle asp-for="IsHot" label="熱銷" hint="列表顯示熱銷標記" />
</form>
```

公共属性：`asp-for / label / hint / required`；`ta-input` 额外支持 `type / placeholder / step / min / max`；`ta-select` 支持 `items / include-empty / empty-text`；`ta-textarea` 支持 `rows / placeholder`。
样式固定为 TailAdmin 官方表单控件（`h-11 rounded-lg border border-gray-300 ... focus:ring-3 focus:ring-brand-500/20`），不再提供 `size` / `variant` 等 daisyUI 参数。
错误容器统一输出 `data-valmsg-for="字段名"`，由 `Ta.form.applyErrors` 回填。

## 5. 前端 JS API

所有 API 挂在 `window.Ta`，禁在页面内写 `Alpine.data()` 或内联 `<script>` 业务逻辑。

### 5.1 请求

```js
const res = await Ta.http.get('/Admin/Goods/List', { page: 1, limit: 20 }, { silent: true });
await Ta.http.postForm('/Admin/Goods/Save', { Id: 0, GoodsName: '測試' }); // 自动带防伪令牌
await Ta.http.upload('/Admin/Goods/UploadImage', formData, { onProgress: p => {} });
```

- `401`：自动跳转 `Ta.config.loginUrl`；
- `400/403/404/500`：统一 Toast，500 额外输出 `X-Trace-Id`；
- `{ silent: true }` 不弹 Toast（表格自行展示错误）。

### 5.2 提示与确认

```js
Ta.toast.success('保存成功');
Ta.toast.error('失敗原因', { duration: 0 });
const ok = await Ta.confirm({ title: '刪除確認', text: '不可恢復', danger: true });
```

### 5.3 弹窗

静态弹窗：

```cshtml
<dialog class="ta-dialog" x-data="taModal({ id: 'goodsEdit', title: '編輯商品', size: 'lg' })">
    <div class="ta-dialog-card" x-bind:class="boxClass">
        <h3 class="text-lg font-semibold text-gray-800 dark:text-white/90" x-text="title"></h3>
        <div x-ref="body" class="mt-4"></div>
        <div class="mt-6 flex flex-col-reverse justify-end gap-3 sm:flex-row">
            <button type="button" class="inline-flex items-center justify-center rounded-lg border border-gray-300 bg-white px-4 py-2.5 text-theme-sm font-medium text-gray-700 shadow-theme-xs hover:bg-gray-50 dark:border-gray-700 dark:bg-gray-800 dark:text-gray-400" x-on:click="close()">取消</button>
            <button type="button" class="inline-flex items-center justify-center rounded-lg bg-brand-500 px-4 py-2.5 text-theme-sm font-medium text-white shadow-theme-xs hover:bg-brand-600" x-on:click="submit()">保存</button>
        </div>
    </div>
</dialog>
```

- `Ta.modal.load(id, url, params)`：拉取 Partial 填入 `x-ref="body"`；
- `Ta.modal.submit(id)` / 弹窗内 `submit()`：提交内部 `<form>`，成功关闭并派发 `ta:modal-submitted`；
- `Ta.modal.close(id)`、`Ta.modal.open(id, data)`；
- `Ta.previewImage(url)`：图片预览。

### 5.4 表格

```cshtml
<div x-data="taTable({ ... })" x-init="load()"> ... </div>
```

方法：`load / reload / refresh / setPage / setLimit / applyFilters / toggleSort / pageCount / pageList`。
通过 `Ta.tables['goodsTable'].refresh()` 可在任意位置刷新表格。
搜索弹窗通过 `document.dispatchEvent(new CustomEvent('ta:table-filter', { detail: { tableId, keyword } }))` 驱动。

```cshtml
    <template x-for="item in items" :key="item.uid">

    </template>
</div>
```

### 5.7 日期

```cshtml
<input type="text" x-datepicker="{ dateFormat: 'Y-m-d' }" />
```

需在页面设置 `ViewData["UseDatepicker"] = true` 以引入 flatpickr。

### 5.8 主题

```js
Ta.theme.toggle();           // 明暗切换并持久化到 localStorage["darkMode"]
Ta.theme.set('dark');
Ta.theme.current();
```

明暗通过 `<html class="dark">` 驱动，与 TailAdmin 官方一致；不再使用 `data-theme` / `theme-dark` 类。
