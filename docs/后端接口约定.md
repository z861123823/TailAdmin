# 后端接口约定

所有后台页面统一遵循以下契约；新增接口必须先对齐本文，再写页面。

## 1. 列表接口

```
GET /Admin/{Controller}/List?page=1&limit=20&sortField=Price&sortOrder=asc&keyword=xxx
```

响应（字段名固定为小写）：

```json
{
  "code": 0,
  "msg": "",
  "count": 36,
  "data": [ { "Id": 1, "GoodsName": "無線藍牙耳機", "Price": 299.00 } ]
}
```

约定：

- `count` 为过滤后的总条数，不是当前页条数；
- `data` 无数据时必须是 `[]`，禁止返回 `null`；
- `page` 最小 1，`limit` 建议 `Math.Clamp(limit, 1, 200)`；
- `sortField` 必须服务端白名单映射，未知字段回退默认排序，禁止拼接 SQL；
- `keyword` 为空表示查询全部；空结果仍是 200。

前端表格默认发送 `page / limit / sortField / sortOrder / keyword`，需要额外筛选时通过 `TaTableModel.Params` 追加固定参数。

## 2. 写操作接口

```
POST /Admin/{Controller}/Save | Delete | SetFlag
Content-Type: multipart/form-data
```

统一响应（PascalCase）：

```json
{ "Success": true, "Message": "保存成功", "Data": { "Id": 12 }, "Errors": null }
{ "Success": false, "Message": "參數校驗失敗", "Errors": { "GoodsName": ["商品名稱不能為空"] } }
```

- `Errors` 的键必须是模型属性名（`GoodsName`），值为错误消息数组；
- 前端 `Ta.form.applyErrors(form, res.Errors)` 会自动定位 `[data-valmsg-for]` 与字段控件；
- 业务失败同样返回 HTTP 200 + `Success=false`，避免前端把可预期校验失败当异常；
- 新增/更新共用一个 `Save` 动作，`Id=0` 视为新增。

## 3. 防伪令牌

- 控制器统一标注 `[AutoValidateAntiforgeryToken]`；只读 GET 不参与校验；
- 布局输出 `@Html.AntiForgeryToken()`，`Ta.http` 自动附带隐藏域与 `RequestVerificationToken` 请求头；
- 缺失或过期令牌返回 **400**，前端提示「頁面已過期，請重新整理」；
- 新增 POST 动作若漏加校验，`AntiforgeryCoverageTests` 会失败。

## 4. 状态码约定

| 状态码 | 场景 | 前端行为 |
| --- | --- | --- |
| 200 | 成功（含业务失败） | 读取 `Success` 判断 |
| 400 | 防伪令牌缺失/失效、参数非法 | Toast 提示错误消息 |
| 401 | 登录过期（AJAX 请求） | 跳转 `AdminUi:LoginPath`，带 `returnUrl` |
| 403 | 无权限 | Toast 提示 |
| 404 | 资源不存在 | Toast 提示 |
| 500 | 未捕获异常 | Toast「系統繁忙」，控制台打印 `X-Trace-Id` |

非 AJAX 的 401 走 Cookie 默认跳转登录页。判断依据：`X-Requested-With: XMLHttpRequest` 或 `Accept` 含 `application/json`。

## 5. 图片上传

```
POST /Admin/{Controller}/UploadImage
```

支持两种通道：

1. `multipart/form-data`：字段名 `file`，建议限制 2MB；
2. Base64：字段名 `base64`，格式 `data:image/png;base64,...`，建议限制 512KB（富文本小图场景）。

成功响应：

```json
{ "Success": true, "Message": "上傳成功",
  "Data": { "PicId": 1763000000000, "PicName": "20261123_xxx.png", "PicUrl": "/Uploads/2026/11/20261123_xxx.png" } }
```

服务端必须校验：扩展名白名单、文件头魔数、体积上限，落盘前生成新文件名，禁止使用客户端原始文件名。

## 6. 远程搜索（多选/标签）

```
GET /Admin/{Controller}/TagSearch?keyword=新&ids=新品,熱銷
```

```json
{ "Success": true, "Message": "", "Data": [ { "Value": "新品", "Label": "新品", "Disabled": false } ] }
```

`ids` 存在时优先按 ID 回显已选项，用于编辑弹窗初始化。

## 7. 安全与渲染

- 页面数据一律使用 `x-text` 渲染，禁止 `x-html`、禁止把用户数据拼进 `onclick`；
- 服务端输出统一走 Razor 编码；如需原样中文可在宿主配置 `WebEncoderOptions`（示例宿主已配置）；
- 列表排序、分页参数必须服务端白名单/夹取；
- 上传文件只允许白名单类型，保存路径不得由用户控制；
- 接口异常不得把堆栈或数据库信息返回给前端，只返回通用文案 + `X-Trace-Id`。
