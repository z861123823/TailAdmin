## 破坏性说明

- 无（首次发布）。

## 升级步骤

1. 还原并打包：

```powershell
./build/build-frontend.ps1
./build/pack-nuget.ps1
```

2. 安装或升级包：

```powershell
dotnet add package TailAdmin.Templates.Rcl --version 1.0.0 --source ./artifacts
./build/publish-local.ps1 -ReinstallTemplate
```

3. 宿主 `Program.cs` 注册：

```csharp
builder.Services.AddTailAdminUi(builder.Configuration);
builder.Services.AddScoped<ICurrentAdmin, MyCurrentAdmin>();
```

4. 页面接入布局并设置 `ViewData["MenuKey"]`；菜单在 `AdminUi:Menu` 中按权限配置。

## 已知限制

- 示例宿主使用内存仓储，仅用于演示；生产项目请替换为 SqlSugar + SQL Server/MySQL 实现。
- 前端构建需要 Node.js（仅构建期），运行时不依赖 Node 与 CDN。
- 模板生成的项目请放在本仓库之外，避免继承仓库的中央包管理配置（`Directory.Packages.props`）。
- 换品牌主题需要重新构建 CSS 并提交产物；尚无图形化主题编辑器。
