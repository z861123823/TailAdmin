# 官方界面基线重构记录

## 1. 背景

前一版以 daisyUI 组件类按 TailAdmin 外观重搭页面，与官方演示站（https://demo.tailadmin.com/）仍有明显差距。本次调整为依据用户要求，直接以 **TailAdmin 官方 HTML 版源码为基座**，保留官方 HTML 结构、Tailwind 类名、间距/阴影/字体与组件外观，把官方页面改造成 Razor 布局与 Partial。

## 2. 基线版本

- 本模板版本：`TailAdmin.Templates.Rcl` 1.1.5 / `TailAdmin.Templates` 1.1.5
- 仓库：`TailAdmin/tailadmin-free-tailwind-dashboard-template`
- 版本：v2.5.1（MIT）
- 样式：Tailwind CSS 4.3.3 + `@tailwindcss/forms` 0.5.9 + `tw-animate-css` 1.4.0
- 脚本：Alpine.js 3.17.2（collapse 3.17.5、persist 3.17.2）、ApexCharts 7.3.0
- 字体：Outfit（改为 `@fontsource/outfit` 本地打包）
- 使用的官方素材：`images/user/owner.png`、`images/shape/grid-01.svg`

## 3. 改动范围

### 3.1 前端构建

- `frontend/tailwind.config.js`、daisyUI 依赖与旧 `.ta-*` 组件层已删除；
- 新增 `frontend/src/css/tailwind.css`：以官方 `style.css` 为基线，保留 `@theme`、`menu-item` / `menu-dropdown-item` 等官方工具类、ApexCharts 与 flatpickr 样式；
- 新增 `frontend/scripts/gen-brand-css.mjs`：从 `brand.json` 生成 `brand-50 ~ brand-950`，默认种子为官方蓝 `#465fff`（暗色 `#7592ff`）；
- `frontend/src/css/layers/tailadmin.css`：仅保留原生 `<dialog>` 兼容层、Toast 容器、字段提示与图标尺寸，不再承载组件外观；
- `build/build-frontend.ps1`：拷贝 Outfit 字体到 `wwwroot/css/files`，产物校验改为官方关键类名。

### 3.2 RCL 视图

- `_TailAdminLayout`：官方 `flex h-screen overflow-hidden` 骨架、sticky 顶栏、`max-w-(--breakpoint-2xl)` 内容区；明暗切换改为官方 `.dark` + `localStorage["darkMode"]`；
- `_Sidebar`：官方 `sidebar` / `menu-item` / `menu-dropdown` 结构与折叠、悬停展开行为；
- `_Topbar`：官方汉堡按钮、搜索框、主题按钮、通知按钮、用户下拉；
- `_PageHeader`：官方标题与 `text-theme-*` 字号；
- `_TaTable` / `_Pagination` / `_TableToolbar`：官方 basic tables 卡片、表头、单元格、分页与查询弹窗；
- `_TailAdminAuthLayout` / 示例登录页：官方 signin 左右分栏、网格封面、输入框与按钮；
- 表单 TagHelper：统一输出官方 `h-11 rounded-lg ...` 控件类与官方开关外观；
- `StatCard`、`_EmptyState`、`_ToastHost`：改为官方卡片、空态、Alert 风格。

### 3.3 示例与模板

- 示例仪表盘按官方 eCommerce 页面重构：统计卡、月度销售、统计面积图、月度目标环形图、最近上架表格、快捷入口；
- 商品列表与分类页沿用官方表格/弹窗结构，登录、分页排序搜索、上传、统一响应与防伪令牌等接口契约未变化；
- `dotnet new` 模板同步更新首页与登录页外观。

## 4. 取舍说明

1. **Tailwind 4 与 daisyUI 冲突**：官方 v2.5.1 使用 Tailwind 4，daisyUI 4 仅支持 Tailwind 3。为保证与官方演示一致，选择 Tailwind 4 并移除 daisyUI，旧组件类不保留。
2. **品牌色**：官方硬编码 `#465fff` 等色值，模板改为构建期由 `brand.json` 生成官方色阶，默认值与官方一致；`AdminUi:BrandName` 写入 `<html data-brand>` 作为标识。
3. **明暗切换**：统一为官方 `.dark` 类与 `localStorage["darkMode"]`，不再使用 `data-theme` / `theme-dark`。
4. **字体**：Outfit 本地打包，去除 Google Fonts 运行时依赖。
5. **弹窗**：保留原生 `<dialog>` 与 `Ta.modal` 行为，通过 `.ta-dialog` / `.ta-dialog-card` 对齐官方弹窗外观。
6. **未纳入**：官方地图、日历、代码编辑器等示例样式与运行时依赖未引入，避免模板体积与依赖膨胀。
