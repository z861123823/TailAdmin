# 主题与换品牌指引

## 1. 基线说明

界面样式直接以 **TailAdmin 官方 HTML 版（`tailadmin-free-tailwind-dashboard-template` v2.5.1，MIT）** 为基座：布局、侧边栏、顶栏、卡片、表格、表单、认证页均沿用官方 HTML 结构与 Tailwind 类名，不再用 daisyUI 组件类重写。

- 官方版本：v2.5.1
- 样式方案：Tailwind CSS 4.3.3 + `@tailwindcss/forms` + `tw-animate-css`
- 字体：Outfit（官方同款，改为 `@fontsource/outfit` 本地打包，无 CDN 依赖）
- 交互：Alpine.js 3.17.2 + `@alpinejs/collapse` + `@alpinejs/persist`
- 图表：ApexCharts 7.3.0（仪表盘月度销售、统计、月度目标）
- 图标与素材：复用 RCL 的 `_Icon`；官方 `owner.png`、`grid-01.svg` 已随 RCL wwwroot 分发，遵循 MIT

## 2. 主题链路

```
frontend/theme/brand.json              ← 唯一品牌色来源（light.primary / dark.primary）
        │
frontend/scripts/gen-brand-css.mjs     ← 生成 brand-50 ~ brand-950 调色板
        │
frontend/src/css/brand.generated.css   ← 构建期产物（自动生成，勿手改）
        │
frontend/src/css/tailwind.css          ← 官方 style.css 基线 + @theme + @source
        │
Tailwind 4 CLI 构建
        │
src/Alys.TailAdmin.Rcl/wwwroot/css/tailadmin.css  ← 产物入库
        │
<html class="dark|light" data-brand="als" data-color-scheme="...">
```

- 明暗切换沿用官方方案：`<html class="dark">` 驱动所有 `dark:` 变体；`localStorage["darkMode"]` 记录用户选择。
- 首屏防闪烁脚本在布局 `<head>` 内联执行，读取 `localStorage["darkMode"]`，其次 `AdminUi:DefaultTheme`，最后跟随系统。
- `AdminUi:BrandName` 写入 `<html data-brand>`，用于标识当前品牌产物；真正的色值由 `brand.json` 在构建期烘入 CSS。

## 3. 换品牌色

1. 修改 `frontend/theme/brand.json` 中 `light.primary` 与 `dark.primary`（其余语义色保留给宿主业务使用）。
2. 保持 `AdminUi:BrandName` 与 `brand.json` 的 `name` 一致，便于识别产物。
3. 重新构建：

```powershell
./build/build-frontend.ps1
```

4. 提交 `brand.json`、`brand.generated.css` 与重新生成的 `tailadmin.css`，确保未装前端工具链的机器也能编译运行。
5. 业务样式只允许使用官方语义类：`bg-brand-500`、`text-gray-800`、`border-gray-200`、`dark:bg-white/[0.03]` 等，禁止写随机十六进制色值。

## 4. 与官方源码的差异与取舍

| 项目 | 官方源码 | 本模板 | 原因 |
| --- | --- | --- | --- |
| CSS 框架 | Tailwind 4.3.3 | 同版本 | 保证视觉一致 |
| daisyUI | 不使用 | **已移除** | daisyUI 4 仅支持 Tailwind 3，与官方 Tailwind 4 基线冲突；旧 daisyUI 组件类已全部删除，不保留两套样式 |
| 品牌色 | 硬编码 `#465fff` 等 | 构建期生成 `brand-50~950` | 保留换品牌能力，默认种子即官方蓝 `#465fff` / 暗色 `#7592ff` |
| 字体 | Google Fonts 外链 | `@fontsource/outfit` 本地字体 | 运行时不依赖 CDN |
| 基础样式 | Tailwind preflight 开启 | 开启 | 官方布局依赖 preflight；RCL 不再提供 `.ta-app` 作用域 reset，宿主同时引入 layui 等旧框架时需自行隔离 |
| 弹窗 | `div` + Alpine 显隐 | 原生 `<dialog>` + `ta-dialog` 兼容层 | 保留现有 `Ta.modal` 行为，外观与官方弹窗一致 |
| 主题类 | `.dark` | `.dark`（不再使用 `data-theme`） | 与官方一致；旧 `als` / `als-dark` 主题名仅作为品牌标识保留 |
| 搜索框 | i18next + 命令面板 | 保留官方输入框外观，按 `AdminUi:EnableSearch` 开关 | 不引入 i18next 运行时依赖，业务文案直接中文 |

> 结论：优先保证与官方演示站视觉一致；daisyUI 仅作为历史实现被移除，品牌色与明暗切换能力通过 CSS 变量保留。

## 5. 视觉约束

- 页面骨架：官方 `flex h-screen overflow-hidden` + 固定侧边栏 + 顶部 sticky header；
- 卡片：`rounded-2xl border border-gray-200 bg-white ... dark:border-gray-800 dark:bg-white/[0.03]`；
- 表头：`border-y border-gray-100`，单元格 `px-5 py-4 text-theme-sm`；
- 主按钮：`rounded-lg bg-brand-500 px-4 py-2.5 text-theme-sm font-medium text-white hover:bg-brand-600`；
- 次按钮：`rounded-lg border border-gray-300 bg-white ... dark:border-gray-700 dark:bg-gray-800`；
- 表单控件：`h-11 rounded-lg border border-gray-300 ... focus:border-brand-300 focus:ring-3 focus:ring-brand-500/20`；
- 图标统一使用 RCL 的 `_Icon` partial，尺寸由 `ta-icon` / `ta-icon-sm` 控制；
- 新增页面必须复用官方布局与组件，保持导航、表头、按钮尺寸、空态一致。

## 6. 版本与依赖锁定

| 依赖 | 版本 | 备注 |
| --- | --- | --- |
| tailwindcss / @tailwindcss/cli | 4.3.3 | 与官方 2.5.1 基线一致 |
| @tailwindcss/forms | 0.5.9 | 官方表单控件样式 |
| tw-animate-css | 1.4.0 | 官方动画类 |
| alpinejs | 3.17.2 | 官方同版本 |
| @alpinejs/collapse / persist | 3.17.5 / 3.17.2 | 侧边栏折叠、状态持久化 |
| apexcharts | 7.3.0 | 仪表盘图表 |
| @tanstack/table-core | 8.21.3 | 服务端分页模式 |
| flatpickr | 4.6.13 | 按需引入 |
| @fontsource/outfit | 5.x | 本地字体 |

升级任何一项都必须单独提交，并附上 `tailadmin.css` / `tailadmin.js` 的产物 diff。Tailwind 大版本不得混用。

## 7. 已知边界

- 已开启 Tailwind preflight；如宿主必须与 layui 等旧框架共存，请在宿主侧做样式隔离，而不是关闭 preflight；
- RCL 只提供布局、组件与主题变量，不接管宿主全局业务样式；
- 官方源码中的地图、日历、代码编辑器等示例样式未纳入本模板，避免引入无用运行时依赖；
- 原生 `<dialog>` 弹窗的遮罩与卡片样式由 `frontend/src/css/layers/tailadmin.css` 提供。
